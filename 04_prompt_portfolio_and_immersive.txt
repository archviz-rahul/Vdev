Style:

  - Thumbnails: 60px height, horizontal scroll, active border
  - Transitions: fade 200ms


360 PANORAMIC VIEWER
--------------------
File: apps/web/src/components/viewers/PanoramaViewer.tsx

Uses Marzipano library for equirectangular panorama rendering.

Setup:
  - Install: pnpm add marzipano
  - Import Marzipano in a dynamic import (no SSR)
  - Create viewer with Marzipano.Viewer element

Features:
  - 360-degree equirectangular image display
  - Drag to rotate (mouse and touch)
  - Gyroscope support on mobile (toggle button)
  - Hotspot markers (clickable, positioned in 3D space)
  - Fullscreen panorama mode
  - Smooth inertia when dragging

Hotspot component: PanoramaHotspot.tsx
  - Position: { yaw: number, pitch: number }
  - Action: teleport | open_info | play_media | external
  - Target: URL or scene ID
  - Style: small circle icon, pulse animation, tooltip on hover
  - Click: executes action (opens info panel, navigates, plays media)

Info panel: AnnotationPanel.tsx
  - Glass card, positioned near hotspot
  - Title and description text
  - Close button
  - Click outside to close
  - Only one open at a time

Admin controls for 360:
  - Upload panoramic image (equirectangular format)
  - Auto-detect equirectangular format (aspect ratio 2:1)
  - Add hotspot: title, link/action, position (click to place)
  - Assign panorama to project
  - Enable/disable gyroscope
  - Set default view (initial yaw/pitch/zoom)
  - Fullscreen toggle


WEBXR 3D MODEL VIEWER
----------------------
File: apps/web/src/components/viewers/ModelViewer.tsx

Uses Babylon.js 8+ for 3D model rendering.

Setup:
  - Install: pnpm add @babylonjs/core @babylonjs/loaders
  - Dynamic import (no SSR)
  - Lazy load Babylon.js engine

Features:
  - Load GLB and GLTF formats
  - Orbit controls (rotate around model)
  - Pan controls (shift+drag)
  - Zoom controls (scroll wheel)
  - Real-time rendering at 60fps
  - AR mode button (WebXR AR session) where supported
  - VR mode button (WebXR VR session) where supported
  - Fullscreen mode
  - Loading indicator (spinner)
  - Error state for unsupported devices

Babylon.js setup:
  - Create Engine instance
  - Create Scene with lighting (hemispheric + directional)
  - Load mesh from GLB/GLTF URL
  - Attach ArcRotateCamera with orbit controls
  - Enable environment reflections
  - Set backgroundColor from theme

AR/VR buttons:
  - Check navigator.xr availability
  - If supported: show AR/VR button
  - If not supported: hide button or show Not supported on this device
  - AR: request immersive-ar session
  - VR: request immersive-vr session

Loading state:
  - Show spinner overlay while model loads
  - Progress indicator if available
  - Hide when model is ready

Error state:
  - If model fails to load: show error message
  - If WebXR not supported: show info message
  - Fallback: show static preview image
