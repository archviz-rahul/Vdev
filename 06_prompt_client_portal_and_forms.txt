CLIENT LOGIN PORTAL
-------------------
File: apps/client-portal/src/app/client-access/page.tsx

Login form with two tabs:
  Tab 1 — Project ID Login:
    - Project ID input (required)
    - Password input (required)
    - Track button
  Tab 2 — Email Login:
    - Email input (required)
    - Password input (required)
    - Login button

Below tabs:
  - Google login button
  - Forgot access code link (sends to admin)

After login: redirect to /client-dashboard

Client dashboard: /client-dashboard
  - Welcome message with client name
  - Assigned project list (cards)
  - Each card: name, status badge, progress bar, last update
  - Click project -> detail view
  - Detail: timeline, deliverables, XR demo launcher, Pixel Streaming launcher, download center, feedback form
  - No admin controls, no billing, no settings

Shared access: /client-view/[accessCode]
  - Public URL, no login required
  - Shows project view with access code validation
  - View-only, no edit actions


PROJECT TRACKING
----------------
File: apps/web/src/components/tracking/ProjectTracker.tsx

Public quick tracking:
  - Project ID input
  - Access Code input
  - Track button
  - Result: timeline view

Timeline view (7 stages):
  1. Brief Received
  2. In Production
  3. Draft Ready
  4. Client Review
  5. Revisions
  6. Final Delivery
  7. Completed

Current stage: highlighted with accent color
Completed: checkmark, green
Pending: gray
Each stage: title, date if reached, optional note
