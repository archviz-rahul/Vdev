PRISMA SCHEMA — packages/database/schema.prisma
Models to create: User, Session, Project, ProjectAsset, ProjectUpdate, Service, PortfolioItem, BlogPost, Category, Tag, Testimonial, FAQ, MediaAsset, Model3D, Panorama, XRLink, PixelStreamSession, FormSubmission, Booking, Lead, NavigationMenu, Theme, DesignSettings, SEOSettings, AnalyticsEvent, AuditLog, Notification, SiteSettings, Client, PricingPlan

User fields: id, email, name, password, role (SUPER_ADMIN/ADMIN/USER/CLIENT), avatar, emailVerified, timestamps
Project fields: id, name, slug, status (BRIEF_RECEIVED through COMPLETED), progress 0-100, serviceCategory, clientName, clientEmail, dates, description, visibility
Service fields: id, name, slug, category (studio/xr-world), description, icon, image, visible, order
PortfolioItem fields: id, title, slug, featuredImage, galleryImages, video, panorama, model3d, category (exterior/interior/animation/xr/360/walkthrough), tags, clientName, location, shortDescription, longDescription, featured, seo fields
BlogPost fields: id, title, slug, content, excerpt, featuredImage, authorId, category, tags, status (draft/published), publishedAt, seo fields
MediaAsset fields: id, name, type, url, size, altText, folder, uploadedBy
Model3D fields: id, name, url, format, size, projectId, previewImage
Panorama fields: id, name, imageUrl, hotspots JSON, projectId, gyroscopeEnabled
FormSubmission fields: id, type, data JSON, status, readAt
Booking fields: id, name, email, phone, company, service, preferredDate, preferredTime, details, status
SiteSettings fields: id, key, value JSON (stores all editable site content)

AUTHENTICATION — NextAuth setup
Install: pnpm add next-auth @auth/prisma-adapter
Providers: Email (magic link), Google OAuth, Credentials (for client portal)
Files: apps/web/src/app/api/auth/[...nextauth]/route.ts, apps/web/src/lib/auth.ts
Session strategy: JWT
Callbacks: signIn, session, jwt

RBAC — Role-based access control
SUPER_ADMIN: full access to everything, manage other admins
ADMIN: manage projects, users, content, cannot manage system settings
USER: assigned projects only, upload assets, manage assigned content
CLIENT: assigned projects only, view timeline, deliverables, demos
Middleware: apps/web/src/middleware.ts — protect /admin/*, /dashboard/*, /client-dashboard/*
Role check utility: apps/web/src/lib/rbac.ts
